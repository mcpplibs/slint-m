# Using mcpplibs.mwrap.slint

`import mcpplibs.mwrap.slint;` declares Slint 1.19.0's C++ API as `<slint.h>` does: every name is upstream's, the very same entity as the header's, so a translation unit may include the header too (before its imports). The SDK is `compat.slint` 1.19.0, a binding of `xim:slint`: `libslint_cpp`, its headers and `slint-compiler`, built from the release tag with upstream CMake's default features (xim-pkgindex `.agents/tools/slint/build-slint.sh`, published to xlings-res/slint).

## Modules

| Module | What it holds |
|---|---|
| `mcpplibs.mwrap.slint` | `slint::` (53 names): `ComponentHandle`, `ComponentWeakHandle`, `Window`, `SharedString`, `SharedVector`, `SharedPixelBuffer`, `Model`, `VectorModel`, `FilterModel`, `MapModel`, `SortModel`, `ReverseModel`, `Color`, `RgbaColor`, `HsvaColor`, `OklchColor`, `Brush`, `Image`, `StyledText`, `Timer`, `TimerMode`, `LogicalPosition` / `Size`, `PhysicalPosition` / `Size`, `run_event_loop`, `quit_event_loop`, `invoke_from_event_loop`, `blocking_invoke_from_event_loop`, `select_backend`, the translation functions …; and `slint::language` (18: `KeyEvent`, `PointerEvent`, `StandardListViewItem`, `TableColumn`, `SortOrder` …). Re-exports `.macros`. |
| `mcpplibs.mwrap.slint.interpreter` | `slint::interpreter`: `ComponentCompiler`, `ComponentDefinition`, `ComponentInstance`, `Value`, `Struct`, `Diagnostic` … |
| `mcpplibs.mwrap.slint.platform` | `slint::platform`: `Platform`, `WindowAdapter`, `AbstractRenderer`, `SoftwareRenderer`, `set_platform`, `update_timers_and_animations` …; the key codes (below). Clang only. |
| `mcpplibs.mwrap.slint.macros` | the 13 `SLINT_FEATURE_*` the headers test, as `inline constexpr bool` in `mcpplibs::mwrap::slint::macros` |

`slint::private_api` and `slint::cbindgen_private` are what the headers' inline functions and generated code reach; they are reachable through the public types and exported by nothing. The source is generated by [tools/gen_exports.py](../tools/gen_exports.py) from clang's AST of the SDK's headers and audited by [tools/check_exports.py](../tools/check_exports.py).

### GCC and the platform API

GCC 16 reports "exposes TU-local entity" for `SoftwareRenderer::render_by_line` (a lambda in its requires-clause) and, with that class left out, crashes with an internal compiler error importing any module built over `slint-platform.h`. So `mcpplibs.mwrap.slint.platform` is empty under GCC; include `<slint-platform.h>` before the imports, which is the same API under every compiler:

```cpp
#include <slint-platform.h>
import mcpplibs.mwrap.slint;
```

### Key codes

`slint::platform::key_codes::A` and its 122 siblings are `constexpr char32_t` constants, whose internal linkage a module cannot export; each is defined, of its type and value, as `mcpplibs::mwrap::slint::platform::key_codes::A`.

## Components from `.slint` files

`mcpp.plugins.slint` (package `mcpplibs.slintgen`, `rules/` of this repository; declared in `[build-dependencies]` with `features = ["slint"]`, which also makes `.slint` a source the rule claims, and compat.slint re-exports `slint-compiler`) runs `slint-compiler` on each `.slint` file of `[build] sources`: one action per file, regenerated when the file or one it imports changes. Its options are upstream CMake's `slint_target_sources` and target properties (`ns`, `library_paths`, `compilation_units`, `edition`, `style`, `embed_resources`, `scale_factor`, `translation_domain`, `bundle_translations`); with `module = "app.ui"` each file also becomes a module exporting its windows, structs, enums and globals. See [rules.md](rules.md).

## The SDK's features

Upstream CMake's desktop defaults: `interpreter`, `backend-winit`, `renderer-femtovg`, `renderer-software`, `accessibility`, `system-tray`, `testing`, and the compiler. `SLINT_FEATURE_RENDERER_SKIA`, `BACKEND_QT`, `EXPERIMENTAL`, `FREESTANDING`, `LIVE_PREVIEW` and the image pixel formats are `false`; `slint::testing` is declared only with `EXPERIMENTAL`, so it is not here. On Linux the library NEEDs `libfontconfig.so.1` (xim:fontconfig) and the C runtime; X11, Wayland and GL are loaded when a window needs them.
